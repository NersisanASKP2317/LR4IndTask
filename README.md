# UBI.167 Security Container
Web-based emulator for oil and gas company. Protects from infected websites using whitelist/blacklist filtering.
##Usage
1. Click "Run" in Replit
2. Enter URL and select action:
   - "Check only" - test URL
   - "Add to whitelist" - always allow
   - "Add to blacklist" - always block
3. Click "Load Demo Data" for examples
4. View statistics and charts
# Variables to change
- 'whitelist'  (line ~420): allowed domains
- 'blacklist'  (line ~421): blocked domains
- Chart colors: edit <style> section
# Requirements
- Modern browser with JavaScript
- Internet for CDN (Chart.js, Vue.js)
